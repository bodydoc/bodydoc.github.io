Zigbee2MQTT - ERS-10TZBVK-AA (Events only)


This blueprint allows you to create automations for the ERS-10TZBVK-AA smart knob using MQTT.

It listens for MQTT events and maps them to Home Assistant actions. Credits to @rdeangel and @pbergman for the blueprint!


**No Commands mode, only event mode**


**Supported Actions:**

- Single Press

- Double Press

- Hold Press

- Rotate Left/Right


**Setup:**

- Ensure your knob is correctly configured in `zigbee2mqtt`.
- Select the correct MQTT topic and device name.
